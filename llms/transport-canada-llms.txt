# Transport Canada

> Transport Canada (Transports Canada) is the federal department that regulates aviation, marine, rail and road transportation in Canada. It publishes no developer portal and no OpenAPI, but it does operate three real, ungated machine-readable interfaces — a Vehicle Recalls Database API, an ArcGIS REST service and an OGC WMS service for Canadian airports — plus bulk CSV/XML extracts indexed through the Government of Canada open data portal. No key, no account, no rate limit, no contract. Everything is licensed under the Open Government Licence – Canada.

Generated by API Evangelist on 2026-07-28. Transport Canada publishes no llms.txt of its own (https://tc.canada.ca/llms.txt → 404, https://open.canada.ca/llms.txt → 404), so this file is generated from the catalog record and the artifacts harvested into https://github.com/api-evangelist/transport-canada.

## What an agent needs to know first

- There is no authentication of any kind. Do not look for an API key, an OAuth flow, or a signup page — none exists. Every endpoint below answers an anonymous GET.
- There is no OpenAPI. The machine-readable contracts that exist are a self-describing service root, an Esri service descriptor and an OGC capabilities document, all harvested verbatim under `capabilities/`.
- The written documentation is a Word document attached to a data-portal record, not a web page. It is dated 2016 and is still accurate.
- Only two datasets have an API. Everything else Transport Canada publishes — CADORS occurrences, the vessel registers, the Air Cargo Security members list, the National Collision Database — is a bulk file. Do not assume an endpoint exists for a dataset; `data.tc.gc.ca` serves exactly one application.
- The Canadian Civil Aircraft Register has neither an API nor a bulk download. It is a search form capped at 1000 results. There is no programmatic route to it.
- Transport Canada does not handle air passenger rights, fare advertising or airline economic licensing. Those belong to the Canadian Transportation Agency, a separate federal body.

## APIs

- [Vehicle Recalls Database API](https://data.tc.gc.ca/v1.3/api/eng/vehicle-recall-database/?format=json): Safety-related recalls for vehicles, tires and child restraints. GET the root to have the service enumerate its own tables and parameters. English `/eng/` and French `/fra/` trees are mirrored.
- [Canadian Airports ArcGIS REST MapServer](https://maps-cartes.services.geo.ca/server_serveur/rest/services/TC/canadian_airports_w_air_navigation_services_en/MapServer?f=json): Airports served by NAV CANADA control towers or flight service stations, with IATA/ICAO codes and coordinates. Layer 0 `/query` returns JSON or geoJSON features.
- [Canadian Airports OGC WMS](https://maps-cartes.services.geo.ca/server_serveur/services/TC/canadian_airports_w_air_navigation_services_en/MapServer/WMSServer?SERVICE=WMS&VERSION=1.3.0&REQUEST=GetCapabilities): The same layer as a conformant OGC Web Map Service 1.3.0 — GetMap, GetFeatureInfo, GetLegendGraphic, GetStyles.
- [Open Government CKAN Action API](https://open.canada.ca/en/access-our-application-programming-interface-api): Indexes Transport Canada's 49 datasets. Operated by Treasury Board Secretariat for the whole Government of Canada, not by Transport Canada. GET only, no key.

## How to query the recalls API

The query is built entirely out of path segments; there are no query-string filters other than `format`.

- Base: `https://data.tc.gc.ca/v1.3/api/{eng|fra}/vehicle-recall-database`
- Tables: `recall`, `recall-summary`
- Parameters: `recall-number`, `make-name`, `manufacturer-name`, `minimum-model-year`, `maximum-model-year`, `year-range`, `model-name`
- One filter: `/recall/recall-number/1977043?format=json`
- Several values (OR): `/recall/make-name/audi|toyota?format=json`
- Several parameters (AND): `/recall/make-name/dodge/year-range/1998-1999?format=json`
- Count instead of records: `/recall/make-name/volkswagen/count?format=json`
- Summary of one recall: `/recall-summary/recall-number/1977043?format=json`
- Format: `?format=json` or `?format=xml`; JSON is the default when the parameter is absent or invalid.
- Responses are `{"ResultSet":[[{"Name":..., "Value":{"Type":"System.String","Literal":...}}]]}` — name/value pairs carrying .NET type names. There is no pagination.

## What does not exist

Recorded so an agent stops looking: no developer portal, no OpenAPI/Swagger/AsyncAPI/GraphQL, no webhooks or event stream, no MCP server, no SDKs, no CLI, no sandbox, no Postman collection, no changelog, no status page, no SLA, no deprecation policy, no rate-limit documentation, no /.well-known/ documents including security.txt, and no support channel keyed to an API. `api.canada.ca`, the Government of Canada API Store, no longer resolves.
